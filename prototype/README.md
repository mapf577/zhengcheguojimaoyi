# Website Prototype

This is a static prototype for the overseas vehicle export and auto parts platform.

Open:

```text
prototype/index.html
```

Data import:

```text
prototype/admin.html
```

Included pages/sections:

- Hero with export-yard visual.
- Vehicle quick search.
- Featured vehicle cards.
- Auto parts category cards.
- Export workflow.
- Supply metrics.
- Contact inquiry form.
- Inquiry drawer with selected products.

Prototype interactions:

- Switch quick search between Vehicles and Auto Parts.
- Filter vehicle cards by type.
- Filter parts cards by category.
- Add vehicles or parts to the inquiry drawer.
- Submit demo contact and inquiry forms.
- Upload vehicle or auto parts CSV files in the admin page.
- Save imported rows to this browser and show them on the website prototype.
- Add a single vehicle or auto part manually.
- Export saved data as CSV.
- Delete one saved row by SKU.
- Use the `images` field to show local asset filenames or external image URLs.
